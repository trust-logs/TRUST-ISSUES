# NaijaPay 🇳🇬

A responsive Nigerian banking-app **front-end demo** built with plain HTML, CSS and JavaScript.

## Included
- Nigerian naira wallet dashboard
- Transfer UI with Nigerian banks
- Airtime and data top-up UI
- Electricity, TV and internet bill-payment UI
- Transaction history
- Responsive desktop/mobile layout
- Client-side demo balance and transaction state

## Important
This is a UI/prototype and **does not move real money**. Before production use, add a secure backend, authentication, KYC/AML controls, double-entry ledger, transaction idempotency, audit logs, encryption, fraud controls and a licensed Nigerian payment/banking infrastructure provider.

Never put payment-provider secret keys in frontend JavaScript.

## Run
Open `index.html` in a browser, or serve the directory with any static web server.
